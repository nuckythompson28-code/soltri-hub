O8000 풀커팅 프로그램 — 6호기

파이프 소재(외경80×내경68)를 외경 황삭 후 폭 15mm 링으로 연속 절단(파팅) — 면취 동시 가공
작업자가 치수·개수·조건을 입력(O8000)하면 → G100이 절삭 로직(O9010)을 호출해 T01 외경황삭 → T02 면취 → T03 절단을 그룹(#107=3개) 단위로 소재 끝까지 반복합니다. 절단할 때 C0.55 면취(#119)가 동시에 들어가고, 가공 수량이 목표(#3902)에 도달하면 알람 11(OVER PARTS)로 알려줍니다. ※이 페이지는 6호기 실기 입력본 기준입니다.
🚨 이 판이 나온 이유 — 2026-06 중간 시작 사고
커서를 #104 줄에 두고 메모리-스타트 → 윗줄(#120 수량)이 실행되지 않음 → 전체 길이 #100이 0.1로 계산 → 잔존 변수가 길이검사까지 꺼버림 → 워크 원점이 척 코앞으로 설정되어 공구가 척으로 돌진.
재발 방지를 위해 통행권(샌드위치 키) + 절대 가드가 추가됐습니다 → 🛡️ 안전 가드 페이지 참고.

① O8000 (MAIN)

작업자 입력 영역. 치수·개수·RPM·이송 설정 후 G100으로 로직 호출. 첫머리 🔑열쇠와 끝 도장은 절대 삭제 금지. 종료 시 수량 카운터(#3901/#3902) 체크.

② O9010 (FULL CUTTING)

안전 가드 통과 후 그룹 계산·루프·잔여분 처리. 작업자 수정 금지.

T01 멀티(외경황삭)

외경 80→74.9를 그룹 길이(51.2)만큼 1패스로 절삭. 멀티 공구 전제 — 일반 인서트 교체 금지.

T02 면취

살두께 중앙(X72.45)에서 플런지 — 노출면의 외·내경 모서리 동시 모따기.

T03 절단

C0.55 테이퍼 면취를 만들며 내경 아래(Ø68)까지 관통 → M12 배출. 절삭유는 M51/M52(6호기).

잔여분 처리

13개 = 3개×4그룹 + 마지막 1개. N400에서 잔여 길이로 개수를 재계산해 마무리.

⚠️ 작업자 핵심 주의사항
1. 스타트는 반드시 프로그램 맨 위에서 — 중간 시작하면 알람 25번으로 정지됩니다 (정상 동작!)
2. #506(그룹길이=#505×#107)이 60 미만이어야 함 — 넘으면 #107 줄이기
3. #104(완성 내경 70)는 이 공정에서 가공 안 함 — 내경 보링은 후공정
4. #121(SMALL TUBE)=1은 소형관 전용 — 120mm 길이검사를 끄는 스위치이니 평소엔 0
5. #122(SKIP MARK)=1이면 황삭·마킹 생략 — N203 패치 후에만 정상 동작
6. M00 정지(워크 확인) — 확인 후 사이클 스타트
7. T02/T03는 반대편 공구대라 X 마이너스 좌표로 움직임 — 좌표 보고 놀라지 말 것
💡 사용법
왼쪽에서 프로그램을 고르고, 코드에 호버(PC)/탭(모바일)하면 변수·코드·줄 설명이 뜹니다. 초록색 글씨(GOTO, G100 등)는 누르면 해당 위치·프로그램으로 점프합니다.

🛡️ 안전 가드 — 통행권(샌드위치 키)

중간 시작 사고 재발 방지 장치 — 2026-06-12 · 6호기 기준
O8000 첫머리에서 열쇠(#149=8000)를 발급하고, 파라미터 입력이 모두 끝난 마지막 줄에서 도장(#148=#149+1)을 찍습니다. O9010은 입장할 때 도장이 정확히 8001인지만 검사합니다. 프로그램 맨 위에서 시작하지 않으면 도장이 8001이 될 수 없으므로, 축이 1mm도 움직이기 전에 알람으로 정지합니다. 통과 즉시 열쇠·도장을 0으로 회수하므로 매 사이클 새로 발급받아야 합니다 (1회용).

3. 신규 품번 프로그램은 이 패턴이 포함된 O8000을 복사(템플릿)해서 작성

🔧 가공 형상 다이어그램

소재가 어떻게 제품이 되는지 — 치수에 호버/탭하면 변수 설명이 뜹니다
파이프 소재(Ø80×Ø68)의 바깥만 깎고(OD↓) → 폭 15mm 링으로 잘라냅니다. 구멍(내경)은 이 공정에서 건드리지 않으며, 완성 내경 Ø70은 후공정 보링에서 만듭니다.

① 단면 비교 — 외경만 절삭 (내경은 후공정)

붉은 띠가 이 공정에서 깎여나가는 부분(외경만). 주황 점선 = 후공정에서 보링할 완성 내경. 개념도라 두께는 과장돼 있습니다.

② 제품 1개 단면 — 절단 동시 면취 C0.55 ⭐

옆에서 자른 단면(상·하 대칭). T03 절단 바이트가 45° 테이퍼로 들어가며 모서리에 C0.55 면취를 동시에 만듭니다. T02는 노출면(앞면) 모서리를 미리 면취합니다.

③ 소재 분할 — 그룹(3개) 황삭 후 하나씩 절단

척은 왼쪽, 가공은 오른쪽(소재 끝)→왼쪽. T01이 한 그룹(#107=3개) 길이를 한 번에 황삭하고, T02 면취→T03 절단을 3회 반복. 그룹마다 워크 원점을 #506만큼 밀어 같은 좌표를 재사용합니다.
💡 핵심 공식
1개 점유 #505 = #105(제품폭 15)+#106(톱폭 1.9) = 16.9
한 그룹 #506 = #505 × #107(3) = 50.7 (60 미만 필수 — T01 행정 한계)
전체 길이 #100 = #120(13개) × #505 + 0.1 = 219.8 (6호기: 120 초과여야 통과)
