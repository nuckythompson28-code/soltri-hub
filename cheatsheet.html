🔧 CNC 현장 치트시트

쏠트리 · 예시 O0400 반토막
⚠️ X = 지름 (반지름 아님!) · Z = 길이 (왼쪽 척 방향이 −)

🚨 안전 5수칙

  • 비상정지(빨간버튼) 위치 먼저 확인
  • 회전 중 문 안에 손·도구 금지
  • G00(급속)은 칼이 번개같이 이동
  • 척·오토링크 동작 중 접근 금지
  • 장갑·옷자락·머리카락 말림 주의

📐 좌표 감각

  • X = 지름값 (X64.9 → 지름 64.9)
  • Z = 길이, 척(왼쪽)으로 갈수록 −
  • 면취는 지름이라 좌표에 ×2
  • U / W = X / Z 증분(상대) 이동

⌨️ 핵심 코드

G00급속이동(위험)
G01직선 절삭
G97회전수 일정(RPM)
G98분당 이송
S / F회전수 / 이송속도
M03/M05정회전 / 정지
M00일시정지(소재장착)
M98/M99서브 호출 / 복귀
T01/T021번 / 2번 공구

📥 O0400 입력칸

#120만들 개수
#101/#102원자재 외경/내경
#103/#104완성 외경/내경
#105/#106제품 길이/톱폭
#121면취 타입(3/4)
#123한 묶음 개수
#115~117공구 회전수

🔁 가공 흐름

① 입력(O0400) → ② 계산·검증(O0410) → ③ 면→보링→면취→절단 반복(O7001~4) → ④ 잔여 처리(O7005)
