# O0500 — O0400 기능의 5호기 이식본

상태: 매크로 계산·반복·좌표 검사 완료 / 5호기 실기 검증 전.

O0500은 O0400의 수량 지정 파이프 링 가공을 5호기에 맞춘 프로그램이다. O2026·O2027의 제일연마 홈가공을 추가하는 작업이 아니다. 5호기의 T1 복합 보링바, 아래쪽 T2 절단 바이트, M53/M54, 에어 M51/M52, 초기 G30·U150 및 후퇴 경로를 참고했다. T3 오토링크는 사용하지 않는다.

## 등록 파일

- 통합 원문: `programs/o0500-unit5.nc`
- 개별 파일 묶음: `programs/o0500-unit5-package.zip`
- 메인: **O0500**
- 로직·서브: **O9030, O9031, O9032, O9033, O9034**

6개 프로그램이 한 세트다. 기존 O0400/O9020~O9025 및 O2026/O2027과 호출 번호를 분리했다. 저장소에서 O9030~O9034와의 충돌은 발견되지 않았으며, 실제 5호기에 이미 저장된 프로그램 번호는 별도로 확인해야 한다.

## 입력 방식

O0400과 동일하게 #101~#116에 치수·절삭조건을 입력하고, #120은 수량, #121은 3/4면취, #122는 묶음 황삭 ON/OFF, #123은 묶음 수량, #124는 짧은 소재 세팅 모드다. 사용하지 않는 T3 회전수 #117은 제거했다.

사용자가 선택한 원점 계산:

```
#505 = #105 + #106
#518 = #120 * #505
#100 = #518 + 5.0
```

예제는 **O0400의 입력값**을 유지했다. 소재 Ø80/Ø68, 완성 Ø74.90/Ø70, 길이 15, T2 날 폭 1.90, 13개, 묶음 3개, 4면취, 묶음 황삭 OFF, 1600 rpm이다. 제일연마 도면 치수로 설정된 프로그램이 아니다. 작업할 품목의 치수·공구 보정·절삭조건을 O0500 입력부에 지정한다.

- 피치: 16.90 mm
- 총 제품 소모 길이: 219.70 mm
- 초기 외부 워크 오프셋 Z: 224.70 mm
- 묶음 수량: 3 / 3 / 3 / 3 / 1
- 정상 묶음 선가공 길이: 50.70 mm
- 마지막 1개 선가공 길이: 17.40 mm (O0400의 마지막 묶음 여유 0.50 포함)
- 마지막 절단 지령 Z: −219.70
- 오프셋 Z와 절단 지령 Z의 합: +5.00
- 마지막 선가공이 있는 경우 그 끝은 위 기준 +4.50까지 간다. 5 mm는 **절단 끝 기준 여유**이며 날끝·홀더의 실제 척 간격을 보장하는 수치가 아니다.

5호기 참고 프로그램의 최대 55 / 최소 여유 1을 적용해 실제 묶음 선가공 길이를 54 mm 이하로 검사한다. 마지막 묶음의 +0.5도 검사에 포함한다. #124=1은 200 mm 이하 원점 길이 검사만 건너뛰며 수량·치수·묶음 길이 검사를 해제하지 않는다. 실행 종료 시 #124는 0으로 돌아가지만, 메인 입력문에 1을 적어두면 다음 실행 때 다시 1이 입력되므로 작업 후 입력문도 0으로 되돌린다.

## 기능 매핑

| O0400 분석 페이지 / 정비완본 | O0500 이식본 | 동작 |
|---|---|---|
| O0400 | O0500 | 입력·설정 |
| O0410 / O9020 | O9030 | 수량·묶음·잔량·호출·종료 |
| O7001 / O9021 | O9031 | 초기 황삭·마킹·단면가공 |
| O7002, O7005 / O9022, O9025 | O9032 | 정상/마지막 묶음의 황삭·선가공 |
| O7003 / O9023 | O9033 | 3면취/4면취 |
| O7004 / O9024 | O9034 | 아래쪽 T2 절단·카운팅 |

### 3면취 (#121=3)

1. 묶음 황삭 ON이면 T1 황삭.
2. T1으로 묶음 내·외경 선가공.
3. 제품마다 T1으로 오른쪽 내경·외경 모따기.
4. T2로 왼쪽 외경 모따기와 절단.
5. 왼쪽 내경 모따기 #109는 이 모드에서 가공하지 않는다.

### 4면취 (#121=4)

1. 묶음 황삭 ON이면 T1 황삭.
2. 제품마다 T1으로 오른쪽 두 모따기 → 제품 길이만큼 내·외경 가공 → 왼쪽 두 모따기.
3. T2는 모따기를 중복하지 않고 직선 절단.

O0400의 처음 준비 구간에 있는 **초기 황삭과 마킹은 항상 실행**한다. #122는 그 뒤 묶음 황삭만 제어한다. 초기 마킹 위치는 Z=(제품 길이+날 폭)/3이다.

## 이식 변경점

- T2 X좌표를 음수로 변환하고, 3면취의 T2 대각 이동을 `U+2C / W−C`로 변경했다.
- T1 보링바는 5호기 표 기준 **M53 UP / M54 DOWN**으로 적용했다. T1 X좌표는 양수다.
- T2 접근·완료·후퇴에 O2027의 외경+4, 소재 내경−3.5, 제품 내경−5, 소재 외경+10을 적용했다.
- M51/M52는 에어 ON/OFF, M12는 카운팅, M55는 초기 면취 후진이다. M03은 기존 5호기 표의 역회전 표기를 따른다.
- 원점은 처음 한 번 설정하고, O2027처럼 #522를 전체 피치로 누적한다. 묶음마다 G10 W로 원점을 이동하던 O0400 방식은 사용하지 않는다. 종료 후 G30 복귀와 G10 Z0 정리는 유지했다.
- T1은 절삭 후 제품 앞쪽으로 Z 후퇴한 다음 T2로 전환한다. T2는 절단 후 X를 소재 외경 바깥으로 후퇴하고 Z+10으로 이동한다.
- 묶음 수량을 `min(설정 묶음 수량, 남은 수량)`으로 계산한다. 수량이 묶음보다 적어도 초과 가공하지 않는다. 완료 카운터 #521은 절단 서브가 복귀한 후 증가한다.
- 원본 단면 서브에 없던 M99를 넣고, `N203(FACE CUTTING)2` 및 이송 대입문 뒤의 불필요한 점을 정리했다.
- G01 U0.2를 명시해 직전 G00의 영향을 받지 않게 했다.
- O0400 정비완본의 입력 통행권을 O0500용 500/501로 분리하고, 서브 호출마다 #147을 확인한다. 직접 서브를 실행하는 실수에 대한 진입 검사이며, 검사 뒤 임의 블록에서 시작하는 모든 경우를 막는 장치는 아니다.
- 홈가공, T3, 오토링크, M68/M69 주척 개폐는 추가하지 않았다.

## 검증

`python tests/verify_o0500.py`로 통합 NC 파일을 직접 읽어 검사한다.

- 수량 1/2/3/4/13/20/21/40 × 묶음 1/2/3 × 3/4면취 × 황삭 OFF/ON = **96개 조합**.
- 정확한 절단·M12 횟수, 정상/마지막 묶음 수량, T2 음수 X, 3면취 U/W 방향, 4면취 양쪽 좌표, T1/T2 전환 전 Z 후퇴 검사.
- 제일연마 입력값을 대응시켜 O2027의 20개 T2 절단 X/Z/이송과 비교. 원점은 사용자 선택에 따라 241.80으로 자동 계산되므로 O2027의 고정 246과 다르다.
- 수량·모드·치수·이송 오류, 묶음 길이 경계, 직접 서브 호출이 G10 및 축 이동 전에 정지하는지 확인.

검사는 좌표와 매크로 흐름을 계산한 것으로 공구 형상·보정값, G30 실제 기준점, 기계 이동 한계, PLC 완료 신호, 제어기 선행 해석, 실제 칩 배출·가공 품질을 검증하지 않는다. **장비에 프로그램을 전송하거나 실행하지 않았다.**
