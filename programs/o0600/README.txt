# O0600 — O8000 방식의 5호기 풀커팅

상태: 5호기용 이식본 / 실기 검증 전. 메인 **O0600**, 가공 서브 **O9050**, 두 프로그램이 한 세트다.

사용자 확정 구성은 **T1 복합 보링바 → T2 면취기 → T3 아래쪽 절단**이다. 공장 배치 변경에 따라 T02 면취기, T03 절단바이트로 공구 호출을 교환했다. M코드는 김공장 5호기 표를 따른다.

## O0500과 구분

O8000 방식의 새 프로그램은 O0600으로 분리했다. 기존 O0400 방식 O0500은 3면취 기본값과 원문을 유지하며 `o0500.html`, `programs/o0500/`에서 계속 제공한다. O0500은 O9030~O9034, O0600은 O9050을 호출한다.

**변수 의미가 달라졌다. O0500 입력부를 그대로 복사해서 쓰면 안 된다.** 특히 #107은 묶음 수량, #108~#116은 세 가공 공정의 회전수·이송, #121은 짧은 소재 세팅, #122는 초기 황삭·마킹 생략이다. 3면취는 T2의 앞쪽 면취와 T3 뒤쪽 외경 면취 조합이며 #121=3으로 지정하는 방식이 아니다.

O0600의 메인 진입 키는 기존 이식본의 8500/8501을 유지한다. O0500의 500/501과 구분해 메인과 서브의 잘못된 조합을 검사한다. 실제 CNC에는 O0600과 O9050을 함께 등록한다. O9050 번호가 이미 사용 중인지와 새 T2 공구 보정은 장비에서 확인한다.

## 공구와 M코드

| 기능 | 6호기 O8000 | 5호기 O0600 |
|---|---|---|
| 묶음 내·외경 | T1 | T1 복합 보링바, X 양수 |
| 면취기 | T2 | **T2**, X=−(완성 OD+ID)/2 |
| 절단 | T3 | **T3**, X 음수에서 위로 절입 |
| 보링바 UP / DOWN | M53 / M54 | M53 / M54 |
| 면취기 전진 / 후진 | M56 / M55 | M56 / M55 |
| 에어 ON / OFF | M51 / M52 | M51 / M52 |
| M03 | 정회전 | 5호기 표의 역회전 |
| 수량 카운팅 | M12 | M12 |

오토링크 인출, M170/M171 클램프 및 M68/M69 주척 개폐는 사용하지 않는다. T2 면취 형상·각도·실제 C값은 장착하는 면취기의 날 형상과 보정으로 결정된다. 공구 위치를 바꾼 뒤 T02 면취기와 T03 절단바이트의 보정은 각각 새 위치 기준으로 설정해야 한다. 이 파일은 장비의 공구 보정값을 변경하지 않는다.

## 입력표

| 변수 | 의미 | 기본값 |
|---|---|---|
| #120 | 생산 수량 | 13 |
| #101 / #102 | 소재 외경 / 내경 | 80 / 68 |
| #103 / #104 | 완성 외경 / 내경 | 74.90 / 70 |
| #105 / #106 | 제품 길이 / T3 날 폭 | 15 / 1.90 |
| #107 | 묶음 수량 | 3 |
| #108 / #109 / #110 | T1 보링 시작·끝 rpm / 이송 | 1600 / 1600 / 0.11 |
| #111 / #112 / #113 | T2 면취 시작·끝 rpm / 이송 | 1600 / 1600 / 0.09 |
| #114 / #115 / #116 | T3 절단 시작·끝 rpm / 이송 | 1600 / 1600 / 0.09 |
| #117 | 소재 길이 세팅 위치에서 추가 M00 (1=사용) | 0 |
| #118 | 제품마다 5호기 기준점으로 후퇴 (1=사용) | 0 |
| #119 | 뒤쪽 외경 면취 C | 0.55 |
| #121 | 짧은 소재 세팅: 200 mm 길이 검사만 생략 (1=사용) | 0 |
| #122 | 초기 황삭·마킹 생략 (1=생략, 단면은 실행) | 0 |
| #126 | 시스템 생산 카운터 제한 검사 (1=사용) | 0 |

기본 치수와 절삭조건은 O8000의 예시다. 가공 품목의 치수와 공구 세팅에 맞춰 입력한다. T1 초기 황삭 이송은 O8000처럼 0.15를 회전수에 곱한다.

## 가공 흐름

1. 입력과 진입 키를 검사하고 원점을 설정한다.
2. #117=1이면 T3 X=−(소재 OD+50), Z=날 폭+1.5에서 소재 세팅 M00.
3. T3 Z0에서 M00. #122=0이면 T1 초기 황삭 → T3 Z=피치/3 마킹. T3 단면 가공은 항상 실행한다.
4. T1으로 **실제 묶음 수량 × 피치 +0.5**만큼 내·외경 선가공한다.
5. T2를 면취 위치로 이동하고 M56 전진 → Z 절삭 → `G00 W10. M55;`로 Z축 10 mm 후퇴와 면취기 복귀 → T3 절단 단계로 전환.
6. T3가 뒤쪽 외경 면취(U+2C / W−C) → 내경 안쪽까지 절단 → X 바깥쪽과 Z 앞쪽 후퇴 → M12.
7. #118=1이면 제품별 기준점 후퇴. 묶음이 끝나면 G10 W로 원점을 옮기고 다음 묶음 또는 잔량을 처리한다.
8. 지정 수량이 완료되면 보링바 DOWN, 주축 정지, 기준점 복귀, 외부 워크 Z 오프셋 0 정리.

면취 후 후퇴는 O8000의 N320/N420과 같은 `G00 W10. M55;`를 사용한다. 이식 때 추가했던 `G00 Z[-#521+20.];`는 삭제했다. 이로써 T2에서 T3로 전환할 때의 Z 지령은 면취 위치보다 10 mm 앞이다.

## 자동 원점과 5호기 적용값

사용자 지정 방식을 유지한다.

```
피치 = 제품 길이 + 절단날 폭
원점 Z = 수량 × 피치 + 5.0
```

기본값은 피치 **16.90**, 원점 **224.70**, 묶음 **3 / 3 / 3 / 3 / 1**, 선가공 **51.20 / 51.20 / 51.20 / 51.20 / 17.40 mm**다. T2 면취 지령은 X−72.45, T3 절단 끝은 X−65다.

묶음마다 50.70씩 원점을 이동하여 기본 오프셋은 224.70 → 174.00 → 123.30 → 72.60 → 21.90이 된다. 마지막 절단은 현 워크 Z−16.90, 초기 원점 기준 Z−219.70이며 절단 끝 기준 여유는 5.00이다. 선가공 +0.5 때문에 보링 끝은 이 기준 4.50까지 간다. 실제 홀더와 척의 간격을 보장하는 값은 아니다.

- O2027의 보링 최대 55 / 여유 1을 적용해 선가공 길이(+0.5 포함)가 **54 mm 이하**인지 검사한다.
- T3 단면 끝은 소재 ID−3.5, 절단 끝은 완성 ID−5, 절단 후 X 후퇴는 소재 OD+10이다.
- #118 후퇴는 6호기의 G30 P3 및 W60/U100 대신 5호기 O2027의 **G30 U0 W0 → G00 U150**을 적용했다. 같은 기계 위치를 뜻하는 것은 아니며 5호기의 등록 기준점에 따른다.
- 6호기 원문의 120 mm 검사 대신 기존 5호기 O0500의 200 mm 검사를 유지한다. #121=1이어도 수량·치수·공구 길이 검사는 유지한다.

## O8000에서 보완한 계산

수량이 묶음보다 작으면 첫 묶음부터 남은 수량으로 줄인다. 잔량은 완료 수량으로 계산하므로 원점의 5 mm 여유가 추가 제품 수량으로 계산되지 않는다.

회전수 증분은 초기 입력 #100이 아니라 실제 총 수량과 실제 묶음 수를 기준으로 계산한다. T1은 묶음별, T2/T3는 제품별로 시작 rpm에서 끝 rpm까지 변한다. 1개 또는 1묶음이면 증분을 0으로 두어 0으로 나누지 않는다. 마지막 절삭 뒤에는 범위를 넘는 회전수를 지령하지 않는다.

G100 사용자 매크로 연결은 5호기에서 확인되지 않았으므로 **M98 P9050**으로 직접 호출한다.

#126은 O8000의 #3901/#3902 시스템 카운터 검사를 선택 기능으로 둔 것이다. 5호기의 해당 변수 지원과 M12 연동을 확인한 뒤 1로 설정한다. 기본 0에서는 시스템 카운터 변수를 읽지 않고 내부 지정 수량과 M12로 처리한다. 1이면 시작 전 예정 수량이 목표를 초과할 때 알람 11, 완료 후 목표 도달 시에도 O8000처럼 알람 11이다.

## 검증 범위

`python -X utf8 tests/verify_o0600.py`는 수량 1/2/3/4/13/20 × 묶음 1/2/3 × 세팅·후퇴·마킹 생략 ON/OFF의 **144개 조합**, 회전수 변화와 1개 예외, 잘못된 입력, 진입 키, 시스템 카운터 선택, 파일 일치를 계산 검사한다. O8000의 13개 면취·절단 위치와 이송도 공구 번호를 대응하여 비교한다.

이 검사는 공구 보정, 면취기 실물 형상, G30 등록점, 기계 스트로크, PLC 완료 신호, 실제 가공 품질을 확인하지 않는다. 장비 전송·실기 실행은 하지 않았다.
