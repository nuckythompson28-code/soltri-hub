# 5호기 공구 형상 보정값 사진

2026-09-11 사용자가 제공한 [형상 보정 화면 원본](evidence/unit5-geometry-20260911.png)을 보존했다. 사용자는 1·2·3행이 각각 T01·T02·T03이라고 확인했다. 제어기는 앞서 확인한 FANUC Series 0i-TD이다.

- T01 / G001 / 복합 보링바: X -752.942, Z -543.000, 반경 0.000, TIP 0.
- T02 / G002 / 공압 면취기: X -243.772, Z -542.340, 반경 0.000, TIP 0.
- T03 / G003 / 아래쪽 절단바이트: X -194.772, Z -546.200, 반경 0.000, TIP 0.

사용자는 이 사진의 목적이 멈칫 진단이 아니라 **5호기 정보 등록과 시뮬레이터 정밀화**라고 명시했다. T02 값은 M56으로 면취기가 완전히 전진한 상태에서 맞춘 값이라고 추가 확인했다.

형상값은 machine-setups.js에 한 번 저장하고, machines.html의 5호기 정보와 simulator.html의 O0600 모델이 함께 사용한다. 5호기 정보에는 제어기, 세 공구의 X/Z·반경·TIP, 원본 사진 링크를 표시한다. 시뮬레이터의 "5호기 정보 · 적용한 형상 보정값"에서도 같은 자료를 볼 수 있다.

상대 공구 위치는 T03을 공구대 기준점으로 하여 Z = G03.Z − Gn.Z, 높이 = (G03.X − Gn.X)/2로 계산한다. 기존 시뮬레이터의 X 직경 기준을 유지한다. 결과는 T01: Z −3.200 / 높이 +279.085, T02 전진: Z −3.860 / 높이 +24.500, T03: 0 / 0이다. 작업 원점을 시뮬레이터의 소재 좌표에 맞추며 이 값을 실제 기계 현재 좌표라고 표시하지 않는다.

시뮬레이터는 형상 보정의 좌표계 이동 방식을 사용한다. T 선택 때 이전/새 형상값 차이로 현재 공구 좌표를 환산한 뒤 해당 블록의 X/Z/U/W를 처리한다. T만 있으면 공구대는 정지하고, T와 X가 함께 있으면 실제 X 지령을 이동 경로로 그린다. G10 원점 이동에서도 물리적 위치를 유지하며 다음 이동을 생략하지 않는다. 이 동작은 O0600의 현재 T02 면취/T03 절단 배치에 한정한다.

제어기의 실제 보정 방식 파라미터와 마모값은 미확인이다. 시뮬레이터의 적용 방식을 장비 정보에 표시한다. T02 복귀 스트로크는 기존 개략 모델의 42mm를 유지하며 실측값으로 표시하지 않는다. M56/M55가 헤드를 작동시키고 T 선택만으로는 작동시키지 않는다. 보링바의 공압 스트로크, 홀더 외형, 동작 시간과 간섭은 실제 장비를 재현·검증한 것이 아니다.

근거: 사용자 사진/전진 기준 확인 및 [FANUC B-64304EN-1/02 §5.1 공개 사본](https://www.scribd.com/document/339582541/B-64304EN-1-02-MANUAL-DEL-OPERADOR-TORNO-pdf). 매뉴얼은 공구 이동 방식과 좌표계 이동 방식을 구분한다. 실제 장비 설정을 추정해 변경하지 않는다.

검증은 tests/verify_simulator.cjs의 형상값·T 선택·X 단독·U/W·G10·기준점 초기화·다른 프로그램 격리 검사와 브라우저의 전 공구대/공압/PC/휴대폰/오프라인 검사로 수행한다. 가공 NC와 CNC 설정은 변경하지 않았고 GitHub 푸시도 하지 않았다.
