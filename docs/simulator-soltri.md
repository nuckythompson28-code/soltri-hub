# 쏠트리 CNC 가공 보기

기본 화면은 **5호기 O0500 V2, T3 면취기**다. `programs/o0500-unit5.nc`를 직접 불러오므로 분석 페이지와 같은 원문을 사용한다. NC 파일은 이 변경에서 수정하지 않았다.

## 장비별 표시

| 선택 | T1 | T2 | T3 | 보링바 UP / DOWN | M03 |
|---|---|---|---|---|---|
| 5호기 O0500 V2 | 내·외경 복합 | 아래쪽 절단 | 면취기 | M53 / M54 | 역회전 |
| 5호기 O2026 / 이전 O0500 | 내·외경 복합 | 아래쪽 절단 | 사용 안 함 | M53 / M54 | 역회전 |
| 2호기 O0400 | 내·외경 복합 | 위쪽 절단 | 사용 안 함 | M54 / M53 | 역회전 |
| 6호기 O8000 | 내·외경 복합 | 면취 | 아래쪽 절단 | M53 / M54 | 정회전 |
| 10호기 O0852 | 내·외경 복합 | 위쪽 절단 | 오토링크 | M54 / M53 | 역회전 |

근거는 김공장 `machines.html`의 M코드 대조표와 해당 프로그램의 T·X 지령이다. 5호기 T1 복합 바이트와 아래쪽 T2 배치는 사용자가 확인한 구성이다. O0852는 프로그램의 #133/#134 보링바 코드와 #131/#132 클램프 코드를 우선 적용한다. 임의의 공구 오프셋을 기계 실측값으로 표시하던 기존 갱 뷰는 제거했다.

## 화면과 사용

- 척은 왼쪽, 자유단은 오른쪽. X 양수는 위, 음수는 아래이며 도식의 높이는 X/2다. X 표시 숫자는 직경 지령 그대로다.
- Z 숫자는 현재 워크 좌표이며, 그림의 Z0는 시작 원점이다. G10 W로 원점을 이동하는 프로그램은 이동량을 합산해 연속된 소재 위치에 그린다.
- `다음 이동`은 계산·분기 구간을 건너뛰고 이동을 보여준다. `다음 절단`은 제품 절단 경로로 이동한다. 완료 수량은 M12에 대응하는 절단 경로에서 표시한다.
- `가공부 확대`는 현재 공구 부근을 보여준다. 휴대폰에서는 확대가 기본이다. `전체 보기`로 척과 소재를 함께 볼 수 있다.
- 급속 경로와 이전 제품 경로는 필요할 때 켠다. 코드·변수는 접힌 상태로 시작한다.
- 분리한 TXT/NC 파일은 메인과 서브를 함께 선택한다. 알려진 메인을 우선 배치하고, 중복 프로그램 번호와 빠진 서브를 표시한다.
- M00에서 화면 재생도 멈추며 다시 재생하면 이어진다. M01은 선택 정지 스위치를 가정하지 않아 자동 정지하지 않는다.

## 표시 범위

소재 제거, 척과 공구 모양은 개략도다. T1의 내경 가공은 UP 상태와 설정된 완성 내경을 기준으로 근사한다. 실제 인서트 형상·공구 보정·반경 보정·홀더 간섭·PLC·기계 스트로크를 검증하지 않는다. G28/G30/G53 복귀 위치는 실측값이 없으므로 경로를 연결하지 않는다. 개별 공구 전환도 확인되지 않은 보정 차이를 가공 경로로 연결하지 않는다.

소재 치수는 O0852의 #109~#114와 O0500/O2026/O0400/O8000의 #101~#106을 구분해 읽는다. 아래쪽 절단의 재료 제거는 X 절댓값으로 계산하며, 그리는 경로는 원래 음수 X를 유지한다. 공구별 지령은 미러 복제하지 않는다.

## 검증

- `node tests/verify_simulator.cjs`: 5개 가공 프로그램과 3개 일반 예제의 종료·유한 좌표·카운트, O0500 V2의 T3 면취·T2 절단 좌표·마킹 생략·제품별 후퇴, 5호기 UP/DOWN, G10 W 누적, IF THEN, M00, 서브·라벨 누락, 수량 오류.
- `python -X utf8 tests/verify_simulator_web.py`: PC/390px 휴대폰, 소재 치수, 절단 13/20/13/13/50개, 5호기 T2 방향, 6호기 T3, 오토링크, 코드 펼치기, 확대, V2 파일 2개 불러오기, 서브 누락, 오프라인 새로고침.

O0500은 O9050 서브를 포함하면 V2로 인식하고 T3를 면취기로 표시한다. 이전 O9030~O9034 세트는 이전 변수 배치와 T1/T2 표시를 유지한다. T3 오토링크는 O0852에만 적용한다.
