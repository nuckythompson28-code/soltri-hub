# 쏠트리 CNC 가공 보기

기본 화면은 **5호기 O0600, T2 면취기**다. `programs/o0600-unit5.nc`를 직접 불러오므로 분석 페이지와 같은 원문을 사용한다. O0600의 공구 배치는 T02 면취기, T03 절단바이트로 변경했다.

## 장비별 표시

| 선택 | T1 | T2 | T3 | 보링바 UP / DOWN | M03 |
|---|---|---|---|---|---|
| 5호기 O0600 | 내·외경 복합 | 면취기 | 아래쪽 절단 | M53 / M54 | 역회전 |
| 5호기 O2026 / O0500 | 내·외경 복합 | 아래쪽 절단 | 사용 안 함 | M53 / M54 | 역회전 |
| 2호기 O0400 | 내·외경 복합 | 위쪽 절단 | 사용 안 함 | M54 / M53 | 역회전 |
| 6호기 O8000 | 내·외경 복합 | 면취 | 아래쪽 절단 | M53 / M54 | 정회전 |
| 10호기 O0852 | 내·외경 복합 | 위쪽 절단 | 오토링크 | M54 / M53 | 역회전 |

근거는 김공장 `machines.html`의 M코드 대조표와 해당 프로그램의 T·X 지령이다. 5호기 O0600은 사용자가 제공한 사진을 반영해 T1 복합 바이트, T2 면취기, T3 아래쪽 절단을 한 공구대에 표시한다. 보관용 O0500과 O2026은 원문의 T1/T2 배치를 유지한다. O0852는 프로그램의 #133/#134 보링바 코드와 #131/#132 클램프 코드를 우선 적용한다.

## 5호기 공구대 함께 보기

O0600은 PC와 휴대폰 모두 `공구대 함께 보기`가 기본이다. 사진의 위쪽 T1, 아래쪽 T2와 T3를 하나의 세로 공구대에 연결했다. 공구대의 X/Z 이동은 세 공구의 고정부에 동일하게 적용된다. 선택된 공구와 공압 동작 중인 T2를 밝게 표시하며 나머지 공구도 계속 보여준다.

T2 면취기는 고정 날끝이 아니라 공압으로 돌출되는 헤드다. 실행된 **M56에서 전진**, **M55에서 복귀**하며, T 번호 변경만으로 전·후진하지 않는다. 사용자가 알려준 대로 전진한 T2 날끝을 T3 날끝보다 소재 방향(−Z)으로 **약 2mm 앞**에 표시한다. 면취하는 동안 전진 상태를 유지하고 공구대와 함께 이동한다. M코드가 아직 실행되지 않았다면 공압 지령 대기로 표시한다.

`simulator-unit5-gang.js`의 나머지 상대 배치는 사진을 바탕으로 한 설명용 간격이다. T2의 후진 위치와 전·후진 거리는 실측값이 아니다. T2의 NC 경로 기준은 전진한 작업 위치로 고정해, 공압 헤드만 움직이는 동작이 공구대의 X/Z 이동으로 바뀌지 않도록 했다. 절삭 시 선택 공구 날끝은 기존 NC 지령 경로에 맞춘다. 사진 파일 자체는 게시하지 않는다.

축 이동과 M코드가 같은 블록에 있으면 이해를 돕기 위해 M56은 헤드 전진 후 공구대 접근, M55는 공구대 후퇴 후 헤드 복귀 순서로 그린다. 이때 좌표 숫자와 경로 표시도 공구대 이동에 맞춰 진행한다. 이 순서와 재생 시간은 설명용이며 실제 PLC의 타이밍을 재현한 것은 아니다. 단독 M55/M56도 `다음 이동`과 재생에서 표시한다.

공구 선택이 바뀌는 구간은 공구대 전체가 이동하는 개략 애니메이션으로 보여준다. 이 구간은 `공구 선택 전환 · 배치 개략도`로 표시하며 NC 절삭 경로나 소재 제거 계산에는 넣지 않는다. G30 등 기준점 좌표를 알 수 없는 구간에서는 마지막 공구대 배치를 유지하고 위치 미표시 상태를 안내한다. M53/M54의 실제 스트로크는 모델링하지 않는다.

시뮬레이터는 O0600/O9050 원문을 재생한다. 면취 후 후퇴는 O8000과 같은 W10 M55이며, 이식 때 추가했던 Z[-#521+20.] 이동을 삭제한 원문을 반영한다.

## 화면과 사용

- 척은 왼쪽, 자유단은 오른쪽. X 양수는 위, 음수는 아래이며 도식의 높이는 X/2다. X 표시 숫자는 직경 지령 그대로다.
- Z 숫자는 현재 워크 좌표이며, 그림의 Z0는 시작 원점이다. G10 W로 원점을 이동하는 프로그램은 이동량을 합산해 연속된 소재 위치에 그린다.
- `다음 이동`은 계산·분기 구간을 건너뛰고 이동을 보여준다. `다음 절단`은 제품 절단 경로로 이동한다. 완료 수량은 M12에 대응하는 절단 경로에서 표시한다.
- `공구대 함께 보기`는 5호기 O0600의 공구대 전체를 보여준다. `가공부 확대`는 현재 공구 부근을, `전체 보기`는 척과 소재까지 보여준다. 다른 프로그램은 기존 표시를 사용하며 휴대폰에서 가공부 확대가 기본이다.
- NC 프로그램 창은 기본으로 열린다. PC에서는 가공 화면 오른쪽, 좁은 화면에서는 아래에 배치한다. 현재 실행 줄에 화살표와 배경색을 표시하고 자동으로 스크롤한다. 메인·서브 호출, 반복 가공, 한 줄 이동, 진행 막대 이동도 같은 실행 기록을 따라간다.
- 가공 그림 바로 위에도 현재 프로그램 번호·행 번호·원문 한 줄을 표시하므로 휴대폰에서 전체 프로그램 창까지 내려가지 않아도 현재 위치를 볼 수 있다. 행 번호는 불러온 통합 원문의 줄 번호다. `프로그램 숨기기`로 전체 목록만 접어도 현재 한 줄은 유지한다.
- 급속 경로와 이전 제품 경로는 필요할 때 켠다. 변수는 접힌 상태로 시작한다. 코드 편집을 열면 재생을 멈춘다.
- 분리한 TXT/NC 파일은 메인과 서브를 함께 선택한다. 알려진 메인을 우선 배치하고, 중복 프로그램 번호와 빠진 서브를 표시한다.
- M00에서 화면 재생도 멈추며 다시 재생하면 이어진다. M01은 선택 정지 스위치를 가정하지 않아 자동 정지하지 않는다.

## 표시 범위

소재 제거, 척과 공구 모양은 개략도다. T1의 내경 가공은 UP 상태와 설정된 완성 내경을 기준으로 근사한다. 실제 인서트 형상·공구 보정·반경 보정·홀더 간섭·PLC·기계 스트로크를 검증하지 않는다. G28/G30/G53 복귀 위치는 실측값이 없으므로 경로를 연결하지 않는다. 공구 전환의 개략 애니메이션은 실제 가공 경로와 구분한다.

소재 치수는 O0852의 #109~#114와 O0600/O0500/O2026/O0400/O8000의 #101~#106을 구분해 읽는다. 아래쪽 절단의 재료 제거는 X 절댓값으로 계산하며, 그리는 경로는 원래 음수 X를 유지한다. 공구별 지령은 미러 복제하지 않는다.
