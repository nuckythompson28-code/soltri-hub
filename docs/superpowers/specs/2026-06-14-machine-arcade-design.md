# 기계별 M코드 아케이드 — 설계 문서

작성일: 2026-06-14 · 대상: soltri-hub (김공장) · 파일: `machines.html`

## 목적
작업자가 아케이드 게임처럼 **기계(호기)를 골라 누르면**, 그 기계의 **M코드(기능별)** 와 **연결 프로그램**이 나오는 현장 레퍼런스. 기계마다 같은 기능이라도 M코드가 다르기 때문(예: 에어 ON이 6호기 M51 / 1호기 M57).

## 화면 구성 (2단계)
1. **선택 화면** — C1 주황 네온(아케이드) 톤. 12대 타일 그리드. 타일에 호기 번호 + 전용 프로그램 라벨. 6호기 등 강조 글로우. CRT 스캔라인.
2. **상세 화면** — 호기 번호(네온) + 타입(HA/AL) + 전용 프로그램. ① 기능별 M코드 카드(2열) ② 연결 프로그램 바로가기 버튼. "◀ 뒤로".

## 비주얼
- 기존 김공장 톤 기반(`--bg #0f1216`, `--accent #ff8c42`) + 아케이드 플레어(네온 글로우, 모노스페이스 숫자, CRT 스캔라인).
- 모바일 우선(max-width ~560px), PWA 일관성. 단일 자기완결 HTML 파일.

## 로스터 (12대)
1~10호기 + **13호기=S3**, **14호기=S4**. (11·12·15 제외)

## 기계↔프로그램 매핑
- **O8000**: 3, 6호기
- **O0852**: 1, 7, 8, 9, 10, 14(S4)
- **O0400**: 2, 13(S3)
- **연결 없음**: 4, 5호기 (M코드 카드만 표시)

링크 대상: `o8000.html`, `o0852.html`, `o0400.html` (이미 존재).
