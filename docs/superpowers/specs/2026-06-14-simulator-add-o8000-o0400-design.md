# G코드 시뮬레이터에 O8000·O0400 추가 — 설계 문서

작성일: 2026-06-14 · 대상: soltri-hub `simulator.html`

## 목적
현재 시뮬레이터는 O0852만 실제 실행됨. **O8000(풀커팅)·O0400(반토막)도 O0852처럼 완전 실행 + 공구경로 애니메이션** 되게 추가.

## 현황 (조사 결과)
- simulator.html = FANUC 매크로 인터프리터(JS). `runProgram()`가 GOTO/IF/식/M98 서브호출/변수M코드(M[#131])/G10/G30/G04 등 처리.
- O0852는 `O0852_SRC` 문자열로 임베드 → `SAMPLES`에 등록 → 드롭다운 선택 시 실행.
- 변수 추적 패널은 전역 `KEYVARS`/`VARLBL`(O0852 전용) 사용.

## 변경 사항 (simulator.html 한 파일)
1. **소스 임베드**: `O8000_SRC`(O8000.txt = O8000+O9010), `O0400_SRC`(o0400.html의 src 블록 7개 = O0400+O0410+O7001~7005) 상수 추가. `SAMPLES`에 `O8000`,`O0400` 등록. 드롭다운 `<option>` 2개 추가.
2. **G100 호출 지원** (핵심): `runProgram` 흐름제어에 `G100 → O9010 호출` 분기 추가(M98과 동일 메커니즘, programs['9010'] push). O8000 전용. O0400은 M98이라 불필요.
3. **카운터 가드 시드**: `runProgram` 시작 시 `vars[3901]=0; vars[3902]=999999;` — O8000 끝 `IF[#3901 LT #3902]GOTO2 / #3000=11(OVER PARTS)`가 시뮬에서 알람 없이 정상 종료(M30)되게. 다른 프로그램엔 무해.
4. **프로그램별 변수 라벨**: 전역 KEYVARS/VARLBL → `PROGVARS{852,8000,400}` 맵으로 분리. `applyProgVars(text)`가 `parsePrograms(text).mainKey`로 현재 세트 선택. `recompute()` 시작 시 호출.

## 안 건드리는 것
기존 O0852 동작, 인터프리터 핵심, UI 레이아웃, basic/idod/step 예제.

## 데이터 무결성 확인
- O8000 기본값: #100=219.8>120, #506=50.7<60 → 알람 가드 통과. 안전키 #148=8001 → O9010 통과.
- O0400 기본값: #100=219.8>200, #506=50.7<60 → 가드 통과.
- O0410은 내부적으로 M98 P7001~7005만 사용(G100 없음) → 기존 지원으로 실행.

## 검증
세 프로그램(O0852·O8000·O0400) 각각 불러 실행 → 헤드리스 스크린샷으로 ① 공구경로가 그려지는지 ② 알람/무한루프 없이 끝나는지 확인.
