# 김공장 호기별 프로그램 배정

2026-09-10 사용자 확인: 기존 배정표를 유지하고 5호기는 최신 O0600으로 배정한다. 4호기는 미배정이다.

| 호기 | 배정 프로그램 | 메인과 서브 |
|---|---|---|
| 1·7·8·9·10·14(S4) | O0852 | O0852 + O9001·O9002·O9003 |
| 2·13(S3) | O0400 | O0400 + O0410·O7001~O7005 |
| 3·6 | O8000 | O8000 + O9010 |
| 5 | O0600 | O0600 + O9050 |
| 4 | 미배정 | M코드 자료만 제공 |

5호기 O0600은 T1 보링, T2 면취기, T3 절단 배치다. O2026/O2027은 제일연마 품목 전용으로, O0500/O9030~O9034는 기존 T2 절단 배치의 보관본으로 별도 표시한다. 두 세트는 5호기 화면에서 접힌 항목을 열어 접근한다.

배정표와 M코드 데이터는 `machine-programs.js` 한 곳에 둔다. 홈의 호기 선택, `machines.html`의 상세 화면, 각 프로그램 분석 페이지의 호기 표시는 같은 데이터를 사용한다. 프로그램 페이지의 `?machine=번호`는 배정된 호기에 한해서만 표시 문맥을 선택하며, 프로그램 원문이나 입력값을 수정하지 않는다.

O0852의 연결 원문은 #130=10 기본값이다. O8000 연결 원문은 6호기 기준이며 3호기는 에어·주축 M코드가 다르다. 다른 호기에 배정된 공통 자료는 해당 기준을 화면에 명시한다. 시뮬레이터도 원문의 기준 호기를 표시한다.

이번 변경은 앱의 배정과 탐색 화면 정리다. NC/TXT 원문, ZIP, 내장 CNC 원문, 기계에 등록된 프로그램, 공구 보정은 변경하지 않는다.

검증: `python -X utf8 tests/verify_machine_programs_web.py`로 12대 배정, 보관본 분리, 호기 문맥, 공통 원문 표시, 다운로드·코드 링크, 키보드 접근, 모바일, 오프라인을 확인한다.
