# 김공장 현장 UI 정리

사용자 요청: 업계 표준에 가까운 디자인으로 바꾸고, 기본 테마는 밝은 회색·흰색으로 한다. GitHub 푸시는 별도 요청 전까지 하지 않는다.

ui.css가 공통 색상·글자·간격·버튼·표·반응형 규칙을 정의하고, ui.js가 주 메뉴와 설비 검색/프로그램 필터를 제공한다. 외부 UI 패키지나 웹 폰트 없이 동작하며 서비스워커에 캐시한다. 루트 25개 페이지에 공통 메뉴와 테마를 적용한다. 별도 스캐너 앱과 외부 피복 관리 서비스는 대상에 포함하지 않는다.

- 바탕은 밝은 회색, 주요 패널은 흰색, 본문은 짙은 회색이다. 주요 동작과 선택은 파란색, 오류·주의는 빨강·주황 계열과 텍스트로 구분한다.
- 홈은 설비 선택, 등록 현황, 현황판/시뮬레이터/오류 기록, 작업 도구 순서다. 등록 현황 숫자는 기계 목록에서 계산하며 가동 상태를 뜻하지 않는다.
- 호기 번호 검색은 정확한 번호를 우선한다. 프로그램·제어기명 검색, 프로그램 필터, 결과 없음, 초기화를 지원한다.
- 호기 상세는 데스크톱에서 프로그램과 장비 정보를 나란히, 휴대폰에서는 순서대로 표시한다.
- 원래 배치도 위치와 공구·CNC 원문, 시뮬레이터 계산은 유지한다. 가공 캔버스는 선과 공구가 잘 보이는 어두운 작업 영역으로 유지한다.
- 공통 스타일은 screen 미디어에 한정하여 기존 인쇄 전용 문서 구성을 보존한다.

참고한 설계 원칙:

- [IBM Carbon 데이터 테이블 사용 지침](https://carbondesignsystem.com/components/data-table/usage/): 반복 정보의 일관된 구조와 검색/필터.
- [W3C 글자 대비 지침](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum): 일반 글자 4.5:1, 큰 글자 3:1을 기준으로 가독성을 검토한다.
- [W3C WCAG 2.2 대상 크기 지침](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum): 작은 화면에서 누를 수 있는 영역과 간격을 고려한다. 일반 조작 버튼은 최소 높이 44px로 구성한다.

특정 산업 인증이나 WCAG 전체 적합성을 주장하는 변경은 아니다. 검증은 tests/verify_ui_web.py의 25개 페이지/모바일·데스크톱 탐색, 검색·필터, 인쇄 메뉴 숨김과 기존 프로그램·시뮬레이터·오프라인 검사로 한다. UI 검사는 외부 요청을 차단하여 실제 설비 현황이나 거주자 기록을 수정하지 않는다.
