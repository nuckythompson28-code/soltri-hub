# 5호기 CNC 수동 수정표

`o0600-patch.html`과 `programs/patches/unit5-o9050-manual-patch-20260910.txt`는 CNC 앞에서 O9050을 수동 편집할 때 읽는 안내다. NC 실행 파일이 아니며 O0600 입력값이나 장비 설정을 변경하지 않는다. 김공장 5호기 배정 카드와 O0600 개요에서 열거나 내려받을 수 있고, 서비스워커에 포함해 오프라인에서도 제공한다.

수정 위치는 줄 번호 대신 N203 끝의 후퇴 줄, N310 진입부, N320~N330 첫 절단 이송 직전으로 한정한다. 마지막 구간은 변수 이동 중 중복 증가를 피하도록 하나의 완성 블록으로 제시한다. 추가 면취 후퇴가 남아 있는 초기 T2 면취/T3 절단 버전, 그 줄만 삭제한 버전, 일부 구간이 이미 수정된 버전을 구분한다.

`python -X utf8 scripts/build_o0600_manual_patch.py`로 화면과 TXT를 함께 생성한다. 완성 코드는 현재 `programs/o0600/O9050.nc`에서 읽는다. TXT는 Windows에서 읽기 쉬운 UTF-8 BOM / CRLF 형식이다. 재생성 후에는 기존 코드 예시와 수정 범위가 새 원문에 맞는지도 검토한다.

`python -X utf8 tests/verify_unit5_manual_patch.py`로 수정표의 코드를 가상 적용했을 때 현재 원문과 일치하는지, 부분 적용 및 재적용이 중복 계산을 만들지 않는지, 휴대폰 표시·다운로드·복사·오프라인·5호기 링크를 확인한다. 실제 CNC에 자동으로 패치를 적용하거나 운전하지 않는다.
