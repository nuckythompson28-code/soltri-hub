O8000 / O9010 기계 수정 가이드 — 6호기

안전 가드 패치 · 2026-06-12 · 6호기 실기 입력본 기준 · ← O8000 코드 분석으로
✅ 기존 줄은 한 줄도 고치지 않습니다.
아래 4군데에 새 줄만 끼워 넣으면 끝입니다. (O8000에 2줄 · O9010에 9줄)
파란 줄 = 원본에서 찾을 위치(기준 줄) · 초록 줄 = 그 아래에 새로 입력할 줄
ℹ️ 6호기 버전 확인 결과
· N310은 이미 있음 — 라벨 복구 작업 불필요
· #124 없음 — 길이검사 스위치는 #121(SMALL TUBE)이고 파라미터 블록 안에 있어, 통행권이 맨 위 시작을 보장하면 잔존 문제가 자동 해결됨
· 대신 새 버그 발견: #122(SKIP MARK)=1로 쓰면 GOTO203이 가는데 N203 라벨이 없어 알람 060 — 삽입 ④로 수정
기준 줄 (원본에 이미 있음 — 찾기만) 새로 입력할 줄 회색 = 주변 참고용 (건드리지 않음)

📄 O8000 — 2줄 삽입

삽입 ①N1; 바로 아랫줄에 열쇠 1줄 추가
O8000


기준 줄N1;


+ 입력#149=8000 (SAFETY KEY - DO NOT DELETE);


#120=13; (HOW MANY)


#101=80. (MAT DIA OD);
삽입 ②#100=254; 와 G100 ; 사이에 도장 1줄 추가
#122=0 (SKIP MARK);


기준 줄#100=254;


+ 입력#148=#149+1 (KEY CONFIRM - DO NOT DELETE);


G100 ;


IF[#3901 LT #3902] GOTO 2;

📄 O9010 — 2군데 9줄 삽입 (NE9 잠금 상태면 잠시 풀고 입력)

삽입 ③O9010(...) 바로 아랫줄에 검문소 8줄 추가
%


기준 줄O9010(G100 FULL CUTTING);


+ 입력IF[#148 EQ 8001] GOTO 2;


+ 입력#3000=25 (RESTART FROM TOP);


+ 입력N2;


+ 입력#148=0;


+ 입력#149=0;


+ 입력IF[#120 GE 1] GOTO 3;


+ 입력#3000=20 (CHECK #120 HOWMANY);


+ 입력N3;


#500=0 (W.SHIF ORIGIN);


#501=#101+5.;
삽입 ④마킹 끝과 단면절삭 사이에 N203; 1줄 추가 (SKIP MARK 버그 수정)
N202;


G00 X-[#501] T03;


Z[[#105+#106]/3];


G97 S#516 M03;


기준 줄G98 G01 X-[#103];


+ 입력N203;


G00 X-[#501] T03;


Z0;


G97 S#516 M03 T03;
⚠️ 입력 후 반드시 확인
· 삽입 ③의 N2 / N3, 삽입 ④의 N203이 빠지면 GOTO가 갈 곳이 없어 알람 060이 납니다
· 삽입 ④의 기준 줄 G98 G01 X-[#103];은 N202 구역 안의 마킹 줄입니다 — N331 안의 비슷한 줄(G98 G01 X-[#103]F[#516*#116];)과 혼동 금지
· O8000의 N2(수량 카운터용)와 O9010의 N2(검문용)는 다른 프로그램이라 충돌 없음
· 괄호 안 영문 메시지는 알람 화면에 그대로 표시되므로 오타 없이 입력

🧪 입력 끝나면 — 동작 시험 4가지

  1. 정상 시작: 커서 맨 위 → 스타트 → 평소처럼 가공 시작되면 OK
  2. 중간 시작 시험: 커서를 #104 줄에 두고 스타트 → 알람 25 (RESTART FROM TOP) 뜨고 축이 안 움직이면 OK — 사고 때와 같은 조작이 이제 막히는지 확인
  3. 수량 가드 시험: #120=0으로 바꾸고 맨 위에서 스타트 → 알람 20 (CHECK #120 HOWMANY) 뜨면 OK → #120 원래대로 복구
  4. SKIP MARK 시험: #122=1로 바꾸고 맨 위에서 스타트 → 알람 없이 황삭·마킹을 건너뛰고 단면절삭부터 시작하면 OK → #122=0 복구 — 패치 전에는 알람 060 나던 기능

🔒 마지막 — 기계 설정 (선택이지만 권장)

  1. 파라미터 3202 #4 (NE9) = 1 → O9010(9000번대) 표시·편집 잠금. 단, 위 삽입 ③④를 먼저 끝낸 뒤 잠글 것
