ℹ️ O0852는 왜 이것만 하면 되나요?
O0852는 이미 -9999 전수 검증(빈 파라미터 → 개별 알람 101~130)이 들어있는 신형 구조라 수량 가드나 #124 같은 추가 조치가 필요 없습니다. 다만 검증이 "직전 사이클 값이 남은 채 중간 시작"은 못 잡으므로(둘 다 -9999가 아니라 통과), 통행권만 보강합니다.

⚠️ 입력 후 반드시 확인
· 검문은 O0852 안이 아니라 O9001 머리에 넣습니다 — 가공으로 들어가는 관문(M98 P9001)이 하나뿐이라, 기계설정 구역(N8001~) 어디서 중간 시작해도 전부 걸립니다
· 삽입 ③의 N5 라벨이 빠지면 GOTO가 갈 곳이 없어 알람 060이 납니다
· 검사값은 853입니다 — 다른 프로그램 키를 복사하면 영영 통과 못 합니다
· 괄호 안 영문 메시지는 알람 화면에 그대로 표시되므로 오타 없이 입력

🧪 입력 끝나면 — 동작 시험 3가지

  1. 정상 시작: 커서 맨 위 → 스타트 → 평소처럼 가공 시작되면 OK
  2. 중간 시작 시험: 한 사이클 정상 완료 후, 커서를 #111(FIN OD) 줄에 두고 스타트 → 알람 25 (RESTART FROM TOP) 뜨면 OK — 기존 -9999 검증으로는 통과돼버리던 케이스
  3. 기존 검증 확인: 맨 위에서 시작하되 #111 줄을 지워보면 → 기존 알람 111 (NO #111 FIN OD)이 그대로 뜨면 OK → 줄 복구
