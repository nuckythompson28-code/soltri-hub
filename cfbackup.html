💾 CF카드 프로그램 백업

기계(컨트롤러)에 등록된 모든 NC 프로그램(O번호 전체)을 CF카드로 한 번에 빼는 방법. 위아(현대위아) · FANUC 0i 계열 기준.

🔑 핵심: 프로그램 번호란에 O-9999 를 넣고 PUNCH(출력) 하면 O0001 ~ O9999 전부 한 번에 빠집니다. (한 개만 빼려면 O1234처럼 단일 번호)

📋 절차 (FANUC 0i 계열)

  1. CF카드 삽입 — 컨트롤러 측면 또는 도어 안 메모리카드 슬롯에. 포맷은 FAT / FAT32. 구형 컨트롤러는 2GB 이하 카드 권장.
  2. I/O 채널을 메모리카드로 지정 — SETTING(설정) 화면, 또는 파라미터 No.20 (I/O CHANNEL) = 4 이게 4(메모리카드)가 아니면 카드로 안 나가고 다른 포트로 나가려다 실패합니다.
  3. EDIT 모드 선택 편집 모드여야 출력이 됩니다. (자동/MDI 모드에선 PUNCH 안 뜸)
  4. PROG 키 → 프로그램 화면
  5. 우측 操作 / OPRT 소프트키 → 확장 + → PUNCH 기종에 따라 [출력] / [F 출력] / [F OUTPUT] 으로 표시되기도 합니다.
  6. 프로그램 번호 입력란에 O-9999 또는 -9999 입력 = O0001 ~ O9999 전체 일괄. 단일은 O번호 하나만.
  7. EXEC / 실행 → 카드에 기록 ✅
⚠️ 9000번대(로직·매크로)는 보호 켜져 있으면 빠지지 않습니다
O9010·O9020 같은 로직과 메이커 매크로는 NE9 보호 대상입니다. 전체 백업하려면 잠시 풀고 출력하세요:
· 3202 #4 (NE9) = 0 → 9000번대 잠금 해제
· 3202 #0 (NE8) = 0 → 8000번대(O8000) 잠금 해제
출력 끝나면 다시 1로 잠그기. 안 풀면 정작 중요한 로직이 백업에서 누락됩니다.
💡 자주 막히는 곳
· 카드 인식 안 됨 → 포맷(FAT/FAT32)·용량 확인
· PUNCH 메뉴 안 보임 → EDIT 모드인지 확인
· "I/O ERROR" → 파라미터 No.20 = 4(메모리카드) 확인
· 일부 프로그램만 나옴 → NE8/NE9 보호 때문 (위 경고 참고)

🕹️ 호기별 컨트롤러 모델 · 키 차이

호기위아 기종FANUCCF 슬롯 위치 / 메모
전수조사 예정— 호기별 모델 조사 후 채워넣을 예정 (0i-D/F 세대별 [DEVICE] 선택 차이 포함) —

※ 위아+FANUC 0i 계열은 위 절차가 거의 공통입니다. 0i-D ↔ 0i-F 세대에서 메모리카드 선택([DEVICE]) 위치만 살짝 다른데, 호기별 모델이 정리되면 이 표에 채워 넣습니다.
