오토링크
정면 검은 사각판 / 은색 몸체 띠 / 검은 후면판과 장착 브래킷 / 측면 공압 실린더와 피팅2개.
은색 회전축3개 위의 검은 암이 회전하며 암 끝 은색 원통핀3개가 소재 외경을 안쪽으로 물림.
헤드 정면은 척 방향(음의 NC Z), 핀 축은 주축과 평행. 소재 내경을 벌려 잡는 구조가 아님.
AUTOLINK_HEAD의 기준점은 변경하지 않은 T3. AUTOLINK_JAW_1/2/3은 각각 X축 주위 회전.
AUTOLINK_ARM_1/2/3과 AUTOLINK_PIN_1/2/3은 해당 회전 그룹의 자식이며 길이·크기 고정.
닫힘: 핀 중심 반경=소재 외경/2+핀 반지름. 열림: 반경에 추정 여유8mm 추가.
표시용 추정값: 회전축 반경48, 암 길이31, 핀 반경5/길이18mm, 핀 축방향 범위 T3[-12,+6]mm.
실기 암 길이·핀 치수·헤드 치수·공압 스트로크·내부 기어 연결은 미측정. 모든 해당 치수는 추정 표시.
T3 기준 및 다른 공구의 확인 치수를 유지. 실기 허용 외경이나 충돌 안전범위를 의미하지 않음.

시뮬레이션
가공로컬 x=NC Z, y=NC X/2, z=깊이. 전체그룹을 주축기준-45도회전해 베드방향 표시.
앵커의 XZ 간격은 확인값. 모든 T앵커의 깊이는 같은 추정평면.
T선택 때 엔진이 좌표를 이전형상-새형상 차이로 다시 표현하여 동일 공구대 위치 유지.
이 보정 적용 방식은 시뮬레이션 가정. CNC 파라미터·마모·기계영점·공압 스트로크 미확인.
M53 상승/M54 하강. 보링바의 미측정 공압 스트로크는 미구현.
M64 오토링크 열림/M63 닫힘은 고정 길이 암의 회전으로 표시. 소재 당김은 공구대 전체 Z 이동.
소재는 기존 축대칭 단면 계산 사용. 충돌·흡입물리·실기 시간 검증 아님.
