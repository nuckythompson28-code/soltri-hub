파란 줄 = 원본에서 찾을 위치(기준 줄) · 초록 줄 = 그 아래에 새로 입력할 줄

📄 O0400 — 2줄 삽입

삽입 ①N1; 바로 아랫줄에 열쇠 1줄 추가
O0400(MAIN PROGRAM);


기준 줄N1;


+ 입력#149=400 (SAFETY KEY - DO NOT DELETE);


#120=13; (HOW MANY)


#101=80. (MAT DIA OD);
삽입 ②#100=254; 와 M98 P0410; 사이에 도장 1줄 추가
#124=0 ( 0=NORMAL MODE 1=MANUAL MODE);


기준 줄#100=254;


+ 입력#148=#149+1 (KEY CONFIRM - DO NOT DELETE);


M98 P0410;


M30;

📄 O0410 — 2군데 9줄 삽입

삽입 ③O0410(...) 바로 아랫줄에 검문소 8줄 추가
%


기준 줄O0410(G100 FULL CUTTING);


+ 입력IF[#148 EQ 401] GOTO 2;


+ 입력#3000=25 (RESTART FROM TOP);


+ 입력N2;


+ 입력#148=0;


+ 입력#149=0;


+ 입력IF[#120 GE 1] GOTO 3;


+ 입력#3000=20 (CHECK #120 HOWMANY);


+ 입력N3;


#500=0 (W.SHIF ORIGIN);


#501=[#101+5.];
삽입 ④맨 끝 N450 (EXIT); 바로 아랫줄에 #124 자동 복귀 1줄 추가
IF[#520LT#531] GOTO 420;


기준 줄N450 (EXIT);


+ 입력#124=0 (ONE-SHOT RESET);


G30 U0 W0 M5;


G10 L2 P0 Z0;


M99;
⚠️ 입력 후 반드시 확인
· 삽입 ③의 N2 / N3 라벨이 빠지면 GOTO가 갈 곳이 없어 알람 060이 납니다
· 검사값은 401입니다 — O8000의 8001을 그대로 쓰면 영영 통과 못 합니다
· 괄호 안 영문 메시지는 알람 화면에 그대로 표시되므로 오타 없이 입력

🧪 입력 끝나면 — 동작 시험 3가지

  1. 정상 시작: 커서 맨 위 → 스타트 → 평소처럼 가공 시작되면 OK
  2. 중간 시작 시험: 커서를 #104 줄에 두고 스타트 → 알람 25 (RESTART FROM TOP) 뜨고 축이 안 움직이면 OK
  3. 수량 가드 시험: #120=0으로 바꾸고 맨 위에서 스타트 → 알람 20 (CHECK #120 HOWMANY) 뜨면 OK → #120 원래대로 복구
