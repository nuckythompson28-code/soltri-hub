O0400 정비 완본 가이드

9000번대 이전 + 통행권 안전가드 + NE9 잠금 · 2026-06-15 · ← O0400 코드 분석으로
🔧 O0400 한 번에 정비 — 세 가지를 한 번의 등록으로 끝냅니다:
① 로직·서브를 9000번대로 이전 (NE9로 잠그기 위해) ② 통행권 안전가드(중간시작 차단) ③ NE9 잠금
로직은 한 글자도 안 바뀝니다 — 번호와 안전장치만 추가

STEP A 번호 이전 — 기존 삭제 후 새 번호로 등록

왜? O7000번대·O0410은 NE9 보호 범위(9000~9999) 밖이라 작업자가 편집·삭제할 수 있습니다. 9000번대로 옮겨야 NE9 한 번으로 다 잠깁니다.
기존 번호새 번호역할
O0410→O9020로직 (전체길이·그룹루프·잔여)
O7001→O9021면가공 FACE
O7002→O9022스텝/보링
O7003→O9023면취 CHAMFER
O7004→O9024절단 PARTING
O7005→O9025잔여분 스텝
작업: 기존 O0410 · O7001~O7005를 삭제하고, 완본 파일의 O9020~O9025를 통째로 등록하세요. (완본에는 통행권·#124 리셋이 이미 들어 있습니다.) 호출번호(M98 P7001→P9021 등)도 완본에 다 반영돼 있어 따로 손댈 필요 없습니다.

STEP B 메인 O0400 — 2줄 삽입 + 호출번호 1곳 수정

메인 O0400은 살아있는 채로 수정합니다 (작업자 입력용이라 삭제 안 함).
B-1N1; 바로 아랫줄에 열쇠 1줄 추가
O0400(MAIN PROGRAM);


기준 줄N1;


+ 입력#149=400 (SAFETY KEY - DO NOT DELETE);


#120=13; (HOW MANY)
B-2#100=254; 아래에 도장 1줄 추가 + 호출번호 P0410→P9020
#124=0 ( 0=NORMAL MODE 1=MANUAL MODE);


기준 줄#100=254;


+ 입력#148=#149+1 (KEY CONFIRM - DO NOT DELETE);


수정M98 P9020;   ← 기존 M98 P0410 에서 번호만 변경


M30;
※ O9020(로직) 머리의 통행권 검문·#120 가드와 끝의 #124 1회용 리셋은 STEP A에서 등록하는 완본에 이미 포함돼 있습니다 — 따로 입력할 필요 없습니다. 키는 400 → 도장 401입니다 (O8000의 8001, O0852의 853과 다름 — 프로그램끼리 안 섞이게).

STEP C NE9 잠금

  1. 시운전 1회 — 정상 가공 확인
  2. 파라미터 3202 #4 (NE9) = 1 → O9020~O9025 포함 9000번대 전체 편집·삭제 잠금
⚠️ NE9는 9000번대 "대역 전체"를 한 번에 잠급니다. 이 기계의 O9001~9003(O0852)·O9010(O8000)도 같이 잠기는데, 그게 정상입니다.
NE8(3202 #0)은 절대 켜지 마세요 — 켜면 8000번대 메인(O8000)까지 잠겨 작업자가 파라미터를 못 고칩니다.

🧪 입력 끝나면 — 동작 시험 3가지

  1. 정상 시작: 커서 맨 위 → 스타트 → 평소처럼 가공되면 OK
  2. 중간 시작 시험: 커서를 #104 줄에 두고 스타트 → 알람 25 (RESTART FROM TOP) 뜨고 축이 안 움직이면 OK
  3. 수량 가드 시험: #120=0으로 바꾸고 맨 위에서 스타트 → 알람 20 (CHECK #120 HOWMANY) 뜨면 OK → 복구
📌 다음 단계 (이번 작업 아님) — O0852처럼 호기별 M코드를 #130 머신셀렉트로 변수화하면 코드 1벌로 전 호기를 돌릴 수 있습니다. 단, 기계 컨트롤러가 변수 M코드 M[#변수]를 지원하는지 확인이 먼저입니다.
